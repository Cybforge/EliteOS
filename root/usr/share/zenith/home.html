Zenith Web

A web browser running on the ZenithOS TCP/IP stack. It speaks HTTP and HTTPS (TLS 1.3 with certificate checks against Mozilla's root certificates).

Tips

  • Type an address or a search term into the bar and press Enter.
  • Alt+Left / Alt+Right go back and forward, F5 reloads, the mouse wheel scrolls.
  • This page is /usr/share/zenith/home.html; bookmarks live in ~/.config/zenith/bookmarks.
