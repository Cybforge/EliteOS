ZenithOS Handbook

This page is a local HTML file (/home/user/Documents/zenith.html) rendered by Zenith Web, the browser that ships with ZenithOS. No network is needed to read it.

What is inside

  • Kernel – 64-bit, SMP with up to 64 CPUs, preemptive scheduler, ring 3 processes
  • Desktop – a compositing window manager with shadows, blur and animations
  • Drivers – PS/2, xHCI USB (keyboards, mice, tablets, hubs), Intel e1000 network
  • Network – DHCP, DNS, ICMP, UDP and TCP, plus this browser on top

Keyboard shortcuts

  1. Win opens the start menu, just start typing to search
  2. Alt+Tab switches windows, Alt+F4 closes one
  3. Win+Left / Win+Right snap a window to half the screen
  4. Ctrl+Alt+T opens a terminal

Writing a program

User programs are plain ELF files built against the small ZenithOS libc:

#include <zenith.h>

int main(int argc, char **argv)
{
    printf("Hello from ring 3!\n");
    return 0;
}
Tip: open a terminal and type open http://10.0.2.2:8000/ to load a page served by the QEMU host, or open /home/user to browse your files.
